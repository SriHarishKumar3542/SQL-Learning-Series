# Day 02 — WHERE & Filtering

## 🎯 Objective

Learn how to filter rows in SQL using the `WHERE` clause and comparison operators.

## 📚 Concepts Covered

- WHERE

  - Comparison operators
  - `=`
  - `>`
  - `<`
  - `>=`
  - `<=`
  - `<>`
- Filtering rows based on conditions

## 🧠 What I Learned

The `WHERE` clause is used to retrieve only the rows that satisfy a given condition.

### Basic Syntax

```sql
SELECT column_name
FROM table_name
WHERE condition;
